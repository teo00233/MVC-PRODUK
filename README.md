# MVC PHP Native - Data Produk

Aplikasi CRUD Katalog Barang berbasis arsitektur Model-View-Controller (MVC) PHP Native.

## Fitur Fungsional
- Entitas dengan 5 atribut utama (kode_barang, nama_produk, kategori, harga, stok).
- Operasi lengkap Create, Read, Update, Delete.
- Menggunakan PDO dan Prepared Statements.
- Sistem validasi dan pesan flash notifikasi berhasil/gagal.

## Panduan Penggunaan
1. Import database `database/produk.sql` ke phpMyAdmin (`toko_db`).
2. Akses melalui browser: `http://localhost/mvc-native/public/index.php`
